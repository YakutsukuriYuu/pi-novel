# 审稿

默认不修改正文。先检查用户指定范围，不把局部审稿扩大成全书重写。

读取被审正文及相关前文、规则、人物与计划，创建 review 记录，并引用实际阅读的来源版本。报告结构：

- 严重度：阻断/重要/建议。
- 位置：章节路径、场景或可定位的短引文。
- 证据：与哪个已确认设定或已发生事件冲突。
- 影响：为何损害理解、情节或人物。
- 建议：最小可行修改，必要时提供两个方向。

检查因果、人物动机、知识边界、时空连续性、世界规则、物品、关系、伏笔、节奏、视角、文风和用户要求。

不把个人口味当客观错误；区分硬矛盾、待作者决定、风格建议。避免空泛赞美，也不为凑数量捏造问题。证据不足标记未验证。

报告只能代表当前模型的审查，不声称独立多模型审核。novel_check 的通过也不代表故事正确。

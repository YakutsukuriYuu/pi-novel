# 润色与改稿

先明确改动层级：错别字/句法、文风、场景节奏、结构改稿。
作者只说「润色」时，默认保留事实、视角、人物动机和事件顺序。

1. 完整读取目标段落及其上下文、`设定/文风.md`。
2. 保留有效表达和人物声音，不要为了「更文学」增加无关比喻。
3. 小范围改动用 `novel_patch`：`oldText` 必须在正文中唯一出现，且来自当前 body。
   **不要为了改几句话就重写整章。**
4. 大改用 `novel_write`，并保留不在范围内的内容。
5. `accepted` / `published` 的正文不能直接改：写 `提案/`，或请作者 `reopen`。
6. 保存后核对正文。绑定旧版本的派生记录（状态、事件）会因版本变化而失效 —— **回到正文核对，不要只刷新哈希**。
7. 结构改动要检查后续章节、关系变化、状态和伏笔；列出影响范围，不要自动连锁重写。

润色不能暗中改变：承诺、能力限制、谁知道秘密、物品归属、时间顺序。

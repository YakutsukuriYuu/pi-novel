# 润色与改稿

先明确改动层级：错别字/句法、文风、场景节奏、结构改稿。若用户只说润色，默认保留事实、视角、人物动机和事件顺序。

1. 完整读取目标段落及上下文、文风约定。
2. 保留有效表达和人物声音；不要为了“更文学”增加无关比喻。
3. 小范围使用 novel_patch，oldText 必须唯一且来自当前 body。不要重写整章来改几句话。
4. 大改用 novel_write，并保留不在范围内的内容。
5. 已接受/发布正文不能直接改：创建 proposal 或请作者 reopen。
6. 保存后核对正文；摘要因版本改变可能失效，按新正文重建，不直接伪造来源更新。
7. 结构改动需检查后续章节、关系变化、状态和伏笔；列出影响范围，不自动连锁重写。

润色不能暗中改变承诺、能力限制、谁知道秘密、物品归属和时间顺序。

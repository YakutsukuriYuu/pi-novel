# 构思、设定与规划

## 新书

按用户已有材料逐步整理，不强迫填满所有字段才写作：

1. CREATOR.md：题材、读者、主题、体验、篇幅、内容边界。
2. setting/world.md、rules.md：世界运作方式、能力代价、日常生活与不可违背的限制。
3. character：主人公、对手、配角；分别设计欲望、需求、恐惧、矛盾、声线、初始知识。
4. relationship：双方各自理解的关系，而不是只有“朋友/敌人”标签。
5. location、faction、item、concept：只创建对故事有用的条目，避免堆砌百科。
6. outline/main.md、arc：因果推动的主线、支线、人物弧线、高潮与结局候选。
7. chapter 的 plan.md：每个场景的目标、阻碍、选择、后果。

所有新设定为 draft；请作者通过 confirm 确认关键设定。不要自作主张确认为 canon。

## 规划原则

- 长期大纲可以保留弹性，短期章节计划要可执行。
- 计划记“要发生什么”，事实摘要记“已经写了什么”，不双写同一份叙述。
- 角色转变要有诱因、代价和过程；冲突必须迫使人物选择。
- 伏笔 thread 分清计划埋设、实际埋设、预期回收、实际回收；实际推进引用章节 sources。
- 拟改已接受剧情时创建 proposal，列明涉及的章节和设定，等待作者决定。
- 导入现有小说时先盘点结构，在空的新项目中复制整理，不就地覆盖原稿。章节默认草稿，整理完摘要后交给作者接受。
